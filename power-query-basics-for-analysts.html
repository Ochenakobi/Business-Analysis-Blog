Power Query basics for Excel analysts

Excel · Data preparation

Power Query lets you clean and combine data without copying and pasting. Once a query is set up, refreshing it takes seconds.

Load data from a source, not a copy

Use Data → Get Data to connect to the original file or database. Working from a copy means your report will silently drift from the source.

Keep every step visible

Each transformation appears in the Applied Steps pane. Rename steps with plain words such as "Remove test orders," so anyone can follow the logic later.

Fix types early

Set date and number types at the start. Text dates are the most common cause of wrong totals and failed refreshes.

Test a refresh before you hand over

Add a row to the source, refresh, and check that the new row appears in the output. If it does not, the query is reading a fixed range instead of the full table.
