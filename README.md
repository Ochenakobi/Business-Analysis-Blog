# Kobi on Business Analysis - static blog

Files:
- index.html (home page with post list)
- about.html
- style.css (shared styles)
- posts/*.html (one file per article)

To add a post: copy an existing file in posts/, edit the title, meta description and body, then add a list item to index.html.

## Free hosting options

1. GitHub Pages (free, https://USERNAME.github.io/blog-name/):
   create a public repo, upload this folder's contents, then Settings > Pages > deploy from main branch.
2. Netlify or Cloudflare Pages (free): drag this folder into the dashboard to publish.

## Domain

A free domain is available as the free subdomain each host provides (for example username.github.io or name.netlify.app).
A custom .com costs money each year; a paid domain can be connected to any of these hosts later.
